# Dataset

Place the course-provided `tranrecords.csv` here, or upload it when prompted in Colab.
The CSV and course slides are not included in this distribution.

Required columns: `Amount`, `TranNo`, `Status`, `Department`, `Fiscal Year`, `Month`, `RedFlag`.
Missing values are represented by `:`. Labels are 0 (normal) and 1 (red-flagged).
No dataset redistribution license was supplied with the local course files.
Do not infer that a missing license grants redistribution rights.
